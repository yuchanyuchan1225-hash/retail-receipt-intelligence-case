# Retail Receipt Intelligence — Case Study

公开作品集页面，展示日本线下零售场景中，以微信小程序、小票 OCR 与会员运营连接线下消费和 CRM 数据的业务案例。

## 本地预览

直接在浏览器打开 `index.html`。

## 发布到 GitHub Pages

1. 在 GitHub 新建公开仓库，例如 `retail-receipt-intelligence-case`。
2. 上传本目录全部文件，保留 `assets/` 目录结构。
3. 在仓库 `Settings → Pages` 中选择 `Deploy from a branch`，分支选择 `main` 和 `/(root)`。
4. 保存后，GitHub 会提供公开链接。

页面不包含源码、后台截图、原始运营数据、云账号或供应商信息。
